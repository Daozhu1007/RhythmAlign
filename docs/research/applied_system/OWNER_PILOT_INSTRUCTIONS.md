   - **D3** = one more device: tablet, camera, or second laptop.

   the agent. All devices are your own; no other people are needed, and
   you can do every recording alone.

## The one rule that matters

**Each take = start recording → play the whole file once → stop
recording → save as the take number.**
Leave 2–3 seconds of quiet before you start the playback and after it
ends. Never pause, trim, edit, or convert a recording. If anything goes
wrong, just record the take again and add a letter: `take05_b`.

## Saving

Save every recording into the folder the agent points you to
(`D:\Code\RhythmAlign\experiments\applied_system\pilot_pack\incoming`),
named `take01`, `take02`, … `take12`.
Any file type your device produces is fine (m4a, mp4, wav, …).
