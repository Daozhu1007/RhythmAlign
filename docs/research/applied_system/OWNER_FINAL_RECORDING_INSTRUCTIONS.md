# 你现在要做什么

总共 **3 次录音**（可以分 3 天做），**26 条**，每条约 2.5 分钟，总共约
**1.5 小时**。

播放文件都在电脑上：

- `D:\Code\RhythmAlign\experiments\applied_system\final_pack\buffers\`
  （12 个 wav 文件，用电脑音箱播放）
- `D:\Code\RhythmAlign\experiments\applied_system\final_pack\INTERFERENCE.mp3`
  （拷到第二台能放歌的设备上，只有第 17–20 条用）

你要做的只有五件事：

1. **准备两个录音设备**（都是你自己的）：D1 = 主手机（和上次试录用的同
   一台）；D2 = 另一台手机 / 平板 / 笔记本内置麦克风。
2. **准备两个房间**：房间A = 上次试录用的房间；房间B = 另一个房间（比如
   客厅）。
3. **把 INTERFERENCE.mp3 拷到第二台放歌设备**（另一部手机即可）。
4. **每条录音**：开始录音 → 等两三秒安静 → 按表格完整播放指定文件（不要
   暂停）→ 等两三秒安静 → 停止录音 → 按表格里的名字保存。录坏了就重录，
   文件名加 `_b`，两个都留着。
5. **全部拷进**
   `D:\Code\RhythmAlign\experiments\applied_system\final_pack\incoming\`，
   然后告诉 agent "recordings done"。

## 注意事项

- 三个 session 可以在不同日期做，但同一个 session 内尽量一气呵成。
- 录音设备摆好后不要再挪动；播放音量在 session 内不要变（final11/13/15
  的低音量除外，final17–20 的干扰音量除外）。

- 不要剪辑、转码或"优化"任何录音，原样拷贝。
- 文件名必须是表格里的名字（小写），扩展名用录音 App 默认的即可。

session 之间的休息）。
